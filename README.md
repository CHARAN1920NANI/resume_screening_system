# Resume Screening System using Machine Learning

## Project Overview

The Resume Screening System is a Machine Learning and NLP-based application that automatically screens and ranks resumes according to a given job description.  

This project helps recruiters and HR teams identify the most suitable candidates efficiently by comparing resume skills with job requirements.

The system uses Natural Language Processing (NLP), text vectorization, cosine similarity, and data visualization techniques.

---

# Features

- Resume text processing
- Skill extraction and matching
- Candidate ranking system
- NLP-based similarity checking
- Data visualization using graphs
- Automatic resume scoring
- Beginner-friendly ML project

---

# Technologies Used

- Pandas

- NLP Concepts
- Machine Learning
